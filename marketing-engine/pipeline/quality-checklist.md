# Quality Checklist
## Done-For-You Marketing Engine — Self-Check Before Delivery

Run this check after generating all content. Mark each item PASS or FAIL. Fix any failures before delivering to the client.

---

### Social Media Posts

- [ ] All 30 posts are present (count them)
- [ ] Every post has a clear call to action (link in bio / DM us / shop now / comment below)
- [ ] No post uses hype words: amazing, incredible, game-changing, revolutionary, life-changing, must-have, perfect
- [ ] Tone is consistent across all 30 posts (matches the brand tone from intake form)
- [ ] Each post has 5–8 hashtags
- [ ] No placeholder text [LIKE THIS] remains in any post
- [ ] Posts are the correct mix: 10 product spotlights, 8 lifestyle, 6 problem-solving, 4 behind-the-scenes, 2 promotional

### Product Descriptions

- [ ] All 5 product descriptions are present
- [ ] Each description is 150–250 words (count them)
- [ ] Each description opens with a customer benefit, not the product name
- [ ] Each description includes at least one specific differentiator
- [ ] Keywords are listed at the bottom of each description
- [ ] Each description ends with a purchase prompt
- [ ] No placeholder text remains

### Email Sequence

- [ ] All 5 emails are present
- [ ] Each email has a subject line
- [ ] The 5 emails tell a coherent brand story (read them in sequence — does the narrative flow?)
- [ ] Email 1 contains no hard sell
- [ ] Email 4 is genuinely educational (teaches something useful, not a product pitch)
- [ ] Email 5 contains a specific, clear offer
- [ ] No placeholder text remains (except correctly marked ones like [REAL REVIEW TO INSERT] and [LINK])

### Overall

- [ ] All content reflects the specific products from the intake form (not generic products)
- [ ] All content reflects the correct target customer from the intake form
- [ ] Brand tone from intake form is consistent throughout

---

## How to log the check

After running this checklist, create a file called `quality-check-report.md` in sample-output/ and log each item as PASS or FAIL, with a note on anything that was fixed.
